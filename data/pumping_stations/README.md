# Pumping stations

## Overview

Pumping stations are conceptual entities that contain a set of parallel pumps.
They are the infrastructure that injects water from the production
location into the network.

## Raw Data

The pumping stations module has no dedicated raw dataset. Its generator relies on the output of other modules; see the [data README](../README.md) for the generation order.

## Preprocessing Scripts for Initial Dataset Generation

### Static Properties

The notebook [`pumping_stations-static_properties-generator.ipynb`](./preprocessing-scripts/pumping_stations-static_properties-generator.ipynb) defines one pumping station for each water source.
It then sizes each pumping station using its source's nominal capacity and the province's peak factor, i.e., the highest ratio between total provincial demand and supply during the historical period.
The notebook chooses the pump option and number so that it uses the smallest-nominal-flow pump possible and not more than 
7 pumps. When the target flow cannot be met by a pump option
with 7 pumps, the algorithm selects the next pump option and tries again.

### Heads finder

The notebook [`pumping_stations-heads_finder.ipynb`](./preprocessing-scripts/pumping_stations-heads_finder.ipynb) finds each pumping station's
target head. The target head is used in the BWF evaluator by the algorithm deciding
pump speeds. It simulates the temporary EPANET networks generated by the [connections static properties generator](../connections/preprocessing-scripts/connections-static_properties-generator.ipynb)
to extract the optimal head of each pumping station (active and not) during each 
historical year's peak demand.

## The Narrative

This module has no independent narrative because it contains no dynamic exogenous 
variables. However, new pumping stations are defined when a new source is defined.

## Preprocessing Scripts for Stage Extension

The pumping stations module has no dedicated stage-extension preprocessing script.
New pumping stations appear when a new water source is defined.
The script [`sources_related-static_properties-stage_extender.py`](../preprocessing-scripts/sources_related-static_properties-stage_extender.py)
updates the sources static properties with the new source details and defines
its connection and pumping station.
